# React Native Expo & NativeWind Engineering Skill

Kỹ năng này hướng dẫn `frontend-dev` phát triển ứng dụng di động:

## 1. Thiết Kế Styling Với NativeWind
- Sử dụng className Tailwind CSS chuẩn thông qua NativeWind v4.
- Đảm bảo các kích thước touch target tối thiểu 44x44px cho trải nghiệm chạm ngón tay thoải mái.

## 2. Đồng Bộ Hợp Đồng API
- Chia sẻ cùng kiểu TypeScript Interface (`snake_case`) với Web Portal để đảm bảo khi gọi Backend không bị sai lệch trường dữ liệu.
